Macro-topic adjudication

Instructions and definition (read before starting)

Each item shows two topics of pump.fun tokens. A topic is a group of tokens that a topic model put together; it is shown by a name (written by an LLM from the topic’s samples), its most distinctive terms (c-TF-IDF) and 12 samples that cover the whole topic (image, and the token name, symbol and full description).

Adjudication. These are the pairs on which the two annotators disagreed. Each item shows both answers, with the subject and comment each one wrote. Discuss the pair together and record one joint decision: do topic A and topic B belong to the same macro-topic? Use the note to record the reason, above all when the decision sets a rule for similar pairs.

    • Decide together, on one computer, so that a single file holds the joint decisions.
    • Answers are saved in this browser as you go. When finished, press Export CSV and send the file.
    • Keys: Y yes, N no, ←/→ previous/next.
    • Some images are withheld because an automatic check flagged them as possible sexual content involving minors; judge those samples from their text.
